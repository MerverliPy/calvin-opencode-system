# GitHub PR Skill

Rules:
- Inspect git diff before summarizing.
- Do not claim tests passed unless they ran.
- Include risk and rollback notes.
- Keep PR descriptions reviewer-friendly.
- Prefer small PRs.
- Separate refactors from behavior changes.

PR format:
1. Summary
2. Changes
3. Testing
4. Risks
5. Rollback
