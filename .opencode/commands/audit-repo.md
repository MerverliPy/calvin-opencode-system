# Audit Repository

You are auditing a repository using a generated context pack.

## Input

The user should provide or reference a context pack generated by:

~~~~bash
./scripts/build-context-pack.sh
~~~~

## Task

Analyze the repository context and produce a practical audit.

Focus on:

- repository structure
- documentation
- opencode agents
- opencode commands
- opencode skills
- workflow templates
- registries
- security hygiene
- generated artifacts
- local model routing
- automation opportunities
- future integrations

## Rules

- Separate confirmed findings from assumptions.
- Do not expose secret values.
- Prefer small, reviewable, reversible changes.
- Recommend exact file paths.
- Include command-line steps when changes are recommended.
- Use clarification defaults with short options and a recommended answer.

## Output Format

~~~~markdown
# Repository Audit Report

## Executive Summary

## Current Strengths

## Critical Issues

## Quick Wins

## Structural Recommendations

## opencode Review

## Security and Hygiene Review

## Documentation Review

## Recommended New Files

## Prioritized Execution Plan

## Clarification Defaults
~~~~
