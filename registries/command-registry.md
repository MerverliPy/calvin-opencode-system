# Command Registry

This registry tracks reusable opencode commands.

| Command | Path | Purpose | Status |
|---|---|---|---|
| repo-audit | `.opencode/commands/repo-audit.md` | General non-destructive repository audit. | Active |
| context-pack-audit | `.opencode/commands/context-pack-audit.md` | Audit a repository from a generated context pack or audit upload package. | Active |
| plan-feature | `.opencode/commands/plan-feature.md` | Plan a feature safely without editing files. | Active |
| implement-phase | `.opencode/commands/implement-phase.md` | Implement one approved phase. | Active |
| review-diff | `.opencode/commands/review-diff.md` | Review current git diff without editing. | Active |
| security-audit | `.opencode/commands/security-audit.md` | Perform security-focused repo or diff audit. | Active |
| pr-summary | `.opencode/commands/pr-summary.md` | Create a pull request summary from the current diff. | Active |
| cost-check | `.opencode/commands/cost-check.md` | Audit model and token cost efficiency. | Active |
| local-benchmark | `.opencode/commands/local-benchmark.md` | Benchmark local model suitability for this repo. | Active |
| model-router | `.opencode/commands/model-router.md` | Choose the best local or cloud model route for a task. | Active |
| sandbox-start | `.opencode/commands/sandbox-start.md` | Choose and start the right sandbox level. | Active |
| memory-update | `.opencode/commands/memory-update.md` | Update durable project memory safely. | Active |
| github-multitool | `.opencode/commands/github-multitool.md` | Operate the local GitHub multitool safely. | Active |
